# FractureCare

FractureCare is a web-based second-opinion support system for musculoskeletal X-ray review.

## Project areas

- `frontend/` - React and TypeScript user interface
- `backend/` - Spring Boot REST API, authentication, persistence and reports
- `ai-service/` - Python/TensorFlow model training notebooks and inference API

The system is educational decision-support software. Results require review by a qualified medical professional and are not a diagnosis.

## Local development

See the README files inside the project folders for setup details. Keep secrets in local environment variables and do not commit generated dependencies, datasets or model artifacts.
